# Report sources

LaTeX sources for the project report. **Single column** (`article`, 11pt, a4) —
see the comment at the top of `main.tex` for why, and for what to change if we
switch to two.

## Building

No TeX distribution is installed on the training machine. Either:

- **Overleaf**: upload this folder; `main.tex` is the root document.
- **Locally**: `sudo dnf install texlive-scheme-medium latexmk` then `make`.

## Layout

    main.tex                  preamble, notation macros, section order
    refs.bib                  bibliography
    sections/                 one file per section
    figures/                  generated by `fedrl-export-results` (not yet built)

## Conventions

- `\TODO{...}` marks anything not yet measured. Delete the macro definition in
  `main.tex` to make leftovers fail loudly before submission.
- Numbers in the text come from `docs/final_configuration_and_findings.md` and
  the run directories under `results/`; when a run set changes, update both.
